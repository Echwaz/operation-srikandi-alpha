# Operation Srikandi

**Project Fan-Translation Bahasa Indonesia untuk STEINS;GATE.**

Operation Srikandi adalah project fan translation *STEINS;GATE* ke Bahasa Indonesia yang masih dalam tahap pengembangan. Project ini dibuilt di atas **STEINS;GATE Improvement Patch** dari Committee of Zero.

## Disclaimer

Project ini merupakan fan translation non-komersial dan tidak berafiliasi dengan maupun didukung oleh pihak pemegang hak *STEINS;GATE*.

*STEINS;GATE* dan seluruh aset terkait merupakan hak milik pemegang hak masing-masing.

Informasi lebih lanjut mengenai progres dan rilis akan ditambahkan seiring perkembangan project.
